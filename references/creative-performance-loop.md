# Creative Performance Loop

> The operating tool behind **R37**: the creative system learns from live results. An ad is not finished when it looks good — it is finished when its performance comes back and feeds the next brief.

A skill that only draws beautiful ads is half a system. The other half is **learning**: publish, measure, label what won, and carry the winner forward. This closes the loop so every campaign starts smarter than the last instead of from zero.

---

## 1 · The loop

```
publish → measure → label the winner → feed the next brief → publish again
    ↑                                                              │
    └──────────────────────────────────────────────────────────────┘
```

Each pass turns a measured outcome into the **default** for the next variation matrix (R35). Over time the system accumulates a per-brand "what works here" memory — the winning angle, format, hook and ratio.

---

## 2 · Which metrics

Read the numbers that tell you about the *creative*, not vanity metrics:

| Metric | What it tells you about the creative |
|--------|---------------------------------------|
| **Hook-through / 3s hold** (video) | Did the first second work? → hook axis (R36) |
| **CTR** | Did the creative stop the scroll and earn the click? → visual + hook |
| **CPA / ROAS** | Did it convert? → promise + landing continuity |
| **Frequency / fatigue** | Time to kill the creative and refresh the set |

Match the metric to the axis you rotated. If you tested the hook, the hook-through/CTR split is the read — not overall spend.

---

## 3 · Feeding the next brief

- **Kill silently, promote loudly.** Cut the underperforming variant without ego; give the winner more budget and more variants around it.
- **Carry the winner forward.** The winning angle/format becomes the default row in the next matrix; the losers' data decides which axes to test next.
- **Record the verdict.** Keep the matrix from the last set (R35) with the measured outcome written next to each variant — it is the creative memory that stops you re-testing a loser.

---

## 4 · Creative → landing page continuity

An ad that promises one thing and lands on another **burns budget** (R06). When you deliver a creative, the promise on the ad must be the first message on the landing page:

- The **headline on the ad** and the **headline on the landing page** carry the same promise, in the same words.
- The **CTA** on the ad is answered immediately by the page (no extra step, no surprise offer).
- If you cannot see the page, deliver a **continuity note** with the creative: "this ad promises X, the page must open with X."

This is part of the deliverable, not an afterthought — a broken promise between ad and page is a leak you can fix before spend.

---

## 5 · When not to over-fit

- **Small samples are noise.** One win on a tiny spend is a hint, not a new rule — require a meaningful sample before you crown a winner.
- **Creative fatigue ≠ creative failure.** A creative that wore out after scale did its job; refresh it, don't abandon the angle.
- **The loop beats the gamble.** Testing a little, learning, and compounding is more reliable than betting everything on one "perfect" ad you never measured.
